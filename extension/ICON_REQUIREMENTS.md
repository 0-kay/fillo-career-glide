# Icon Requirements

The Chrome extension requires the following icon files in the `icons/` directory:

## Required Icons

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)  
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Design Guidelines

- Use the Fillo brand colors (purple gradient: #667eea to #764ba2)
- Simple, clean "F" lettermark
- High contrast for visibility at small sizes
- PNG format with transparency

## Temporary Solution

For development/testing, you can:

1. Create simple colored squares with "F" text
2. Use online icon generators
3. Design in Figma/Canva and export as PNG

## Creating Icons

You can create these icons using:
- Figma (free design tool)
- Canva (has icon templates)
- GIMP (free image editor)
- Online favicon generators

The icons should match the logo style used in the popup interface.
