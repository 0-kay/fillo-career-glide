🔧 Fillo Extension Debug Test

📋 Testing Instructions:

1. Make sure you're on localhost:8080 and logged into Fillo
2. Make sure the Fillo extension is installed
3. Run tests below in order
4. Check extension popup after each test

🌐 Test 1: Environment Check

Verify basic environment and Chrome extension availability

🔐 Test 2: Local Storage Check

Check if Supabase auth token exists in localStorage

💾 Test 3: Extension Storage Check

Check what's stored in Chrome extension storage

🔄 Test 4: Manual Token Save

Manually save token from localStorage to extension storage

📡 Test 5: API Test

Test API call with token from extension storage

🧹 Test 6: Clear All Storage

Clear both localStorage and extension storage (for testing)
